Build Algorithm — Step by Step
1
Count character frequencies
Build a hash map (dictionary): char → count. Time complexity: O(n) where n = total characters.
2
Insert all nodes into a min-heap
One leaf node per unique character. Lowest frequency = highest priority. Time: O(k log k).
3
Merge two smallest nodes repeatedly
Pop 2 minimums → create internal node (freq sum) → push back. Repeat k−1 times. This is the greedy step. Time: O(k log k).
4
Assign codes via DFS traversal
Walk tree depth-first. Left branch = '0'. Right branch = '1'. Leaf reached = emit character's binary code. Time: O(k).
